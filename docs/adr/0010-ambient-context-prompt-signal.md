# ADR-0010 — Sensa-Style Ambient Context as Prompt Signal, Not Memory Store

## Status

Accepted

## Context

Ambient signals such as time, timezone, session gap, weather, and location can improve continuity.

## Decision

Use Sensa-style ambient context as prompt input, not as a durable memory store.

## Consequences

Ambient context may influence responses without polluting durable memory or requiring confirmation.
